# reefmetax.com

Static one-page site for Reef (@Reefmetax), Community Builder. Plain HTML/CSS, generated by `build.py` (Python 3.9+, standard library only). Designed for GitHub Pages with the custom domain `reefmetax.com`.

## Daily update procedure

1. **Write `data/news.json`** with today's items (schema below). Only use facts you verified, link every item to a plain `https://x.com/...` post, no hashtags, no buy or sell calls. If there is no verified Doginal Dogs news today, leave `doginal_news` empty (the page then says so) and explain in `notes`.
2. **Run `python3 build.py`**. It fetches live prices and a 7-day BTC chart from CoinGecko, then writes `index.html` and `btc-chart.svg`. If CoinGecko fails, it reuses `data/prices_cache.json` and the page says the prices are last-known.
3. **Publish:** `git add -A && git commit -m "Daily update" && git push`. GitHub Pages redeploys within a minute or two.

Preview locally: open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## `data/news.json` schema

```json
{
  "updated_at": "2026-10-25T01:20:00Z",
  "date_label": "Saturday, Oct 24, 2026",
  "crypto_headlines": [
    {"title": "...", "summary": "...", "source": "Cointelegraph", "url": "https://x.com/.../status/..."}
  ],
  "doginal_news": [
    {"tag": "Doginal Dogs | DDLTCG | Pyth", "title": "...", "summary": "...", "source": "@handle", "url": "https://x.com/.../status/..."}
  ],
  "notes": "Optional line shown under Doginal Dogs News."
}
```

- `updated_at` is UTC ISO 8601. The footer shows it in Eastern Time.
- `date_label` is optional (defaults to the `updated_at` date).
- Links must start with `https://x.com/` (or twitter.com), otherwise they render as `#`.

## Files

| File | Purpose |
| --- | --- |
| `build.py` | Generator: news.json + prices -> index.html, btc-chart.svg |
| `data/news.json` | Daily content (edit this) |
| `data/prices_cache.json` | Last successful price fetch, used as fallback (auto-written) |
| `index.html`, `btc-chart.svg` | Generated output |
| `CNAME` | Custom domain for GitHub Pages (`reefmetax.com`) |
| `.nojekyll` | Tells GitHub Pages to skip Jekyll |
| `favicon.svg`, `og-image.png` | Icon and social card (`og-source.html` is the source for the card) |
